# Agent instructions

Read [METHODOLOGY.md](METHODOLOGY.md), the commissioned Issue, relevant prior reports, and [ARCHITECTURE.md](ARCHITECTURE.md) before work. Treat the informal intent, definitions, assumptions, and allowed scope as acceptance criteria. Get explicit human approval for mathematical scope or trusted-base changes. Keep statements faithful, surface unfinished proofs, and report verification status accurately.

Start with existing libraries and cheap native automation. Escalate to a focused attempt, decomposition, then mathematical review as warranted. Follow the Issue's budget or stopping rule. If it gives none, stop after three substantively different failed strategies without new insight. Stop earlier when a mathematical decision is needed. Inspect a failure before retrying and record what changed. Use checkpoints for substantial work and report measured usage or mark it unknown.

Open a PR for useful, reviewable work. Include the originating Issue, pinned verification commands and results, limitations, and any unresolved goals. Arrange a separate critical review and leave acceptance and merge to the researcher.

Post a [completion report](docs/completion-report.md) on the Issue for every commissioned investigation, including blocked and interrupted work. If posting is unavailable, return the complete report for manual posting. Keep formal results in source, decisions and attempts in Issues and PRs, durable design in architecture, and milestones in the roadmap.
